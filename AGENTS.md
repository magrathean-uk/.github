# Repository context

This is the `magrathean-uk/.github` community-policy repository. It contains Markdown policies and GitHub issue forms. It has no application, package manifest, build, test suite or CI workflow. GitHub uses applicable community files as organisation defaults; this agent context is local to this repository.

`README.md` and `CONTRIBUTING.md` describe shared defaults and repository-specific overrides. The repository also contains legal, security, safe-harbour and conduct documents. Issue forms and `config.yml` include the private security reporting route. `CLAUDE.md` imports this file.

## Documentation check references

These read-only commands inspect scope and whitespace:

```sh
GIT_OPTIONAL_LOCKS=0 git status --short
GIT_OPTIONAL_LOCKS=0 git diff --check
```

Relative links, external destinations, headings and Markdown fences are useful documentation review surfaces. GitHub issue-form structure includes YAML syntax, unique field IDs, supported field types and required-field syntax. GitHub rendering provides a preview of Markdown and forms.
